# Task 1: Style Your CV

## Description
This project applies CSS styling to a personal CV webpage created with HTML.

- Customized headings
- Centered profile image
- Styled tables
- Improved lists and paragraphs
- Hover effects on links

## Technologies Used
- HTML5
- CSS3

## Learning Objectives
- Apply CSS styling
- Use selectors and properties
- Customize colors and fonts
- Style tables, lists, and links
- Improve webpage appearance
